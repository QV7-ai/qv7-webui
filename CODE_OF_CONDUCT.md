# Code of Conduct

QV7 WebUI is a place to build a self-hosted chat interface. People who use the project, open issues, or send changes are expected to be respectful.

## Expected behavior

- Be kind and direct.
- Assume good intent, and ask when something is unclear.
- Disagree about the software, not about the person.
- Give feedback that someone can act on.
- Respect privacy. Do not post other people’s secrets, chats, or personal data.

## Unacceptable behavior

- Insults, harassment, or threats.
- Discrimination or sexual language aimed at a person.
- Publishing private information without permission.
- Sustained disruption of issues, pull requests, or discussions.

## Where this applies

This applies in the [GitHub repository](https://github.com/WLFV/qv7-webui), including issues, pull requests, and discussions. It also applies when you represent the project in public.

## Reporting

Report conduct problems through a [GitHub security advisory](https://github.com/WLFV/qv7-webui/security/advisories/new) so the report stays private. For a general question, open an issue, or use the contact note on the [privacy page](https://qv7.nl/privacy).

Maintainers may edit or remove comments, and may block someone who keeps breaking these rules.
